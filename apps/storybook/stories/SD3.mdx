# SD3

> ⚠️ **Work in progress — not ready for production use.**
>
> The components under **SD3** are part of the next generation of the Sikt
> design system (`@sikt/sd3-design-system`). They are published here for
> visibility and feedback, but the API, styling, and package structure are
> still changing and no stable release is available yet.
>
> Please continue to use the existing component packages (e.g.
> `@sikt/sds-button`) in production applications until SD3 is released.
