# `Field`

## Consume

```sh
npm i -s @sikt/sd3-design-system
```

### React

```js
import { Field } from "@sikt/sd3-design-system";

<Field>
  <Field.Label>Navn</Field.Label>
  <input />
</Field>;
```

### Stylesheets

Import stylesheet:

```css
@layer sd3 /*, my-own-more-specific-layer */;
@import url("@sikt/sd3-design-system") layer(sd3);
```
