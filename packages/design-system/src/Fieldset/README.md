# `Fieldset`

```sh
npm i -s @sikt/sd3-design-system
```

### React

```js

import "@sikt/sd3-design-system/dist/index.css";

<Fieldset>
  <Fieldset.Legend>Velg kategori</Fieldset.Legend>
</Fieldset>;
```
