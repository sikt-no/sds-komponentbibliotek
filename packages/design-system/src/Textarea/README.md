# `Textarea`

```sh
npm i -s @sikt/sd3-design-system
```

### React

```js
import { Textarea } from "@sikt/sd3-design-system";
import "@sikt/sd3-design-system/dist/index.css";

<Textarea aria-label="Kommentar" placeholder="Skriv inn kommentar" />;
```
