# `Header`

## Consume

```sh
npm i -s @sikt/sd3-design-system
```

### React

```js
import { Header } from "@sikt/sd3-design-system";

<Header>
  <Header.Link>
    <Header.Logo />
  </Header.Link>
</Header>;
```

### Stylesheets

Import stylesheet:

```css
@layer sd3 /*, my-own-more-specific-layer */;
@import url("@sikt/sd3-design-system") layer(sd3);
```
